# เมืองออมเงิน (Money gamer)

แอป Android จดรายรับ-รายจ่าย-เงินออม สร้างเมืองด้วยเงินออม พร้อมสแกนสลิปอัตโนมัติ (OCR ออฟไลน์ ภาษาไทย/อังกฤษ)

## ติดตั้งบนมือถือ
1. ไปที่แท็บ **Actions** ใน GitHub → เลือกรัน **Build Android APK** ล่าสุด → ดาวน์โหลด artifact `mueang-om-ngoen-apk`
2. แตก zip ได้ `app-debug.apk` → ส่งเข้ามือถือ แล้วเปิดติดตั้ง (อนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")

## สแกนสลิปอัตโนมัติ
- **แชร์**: เปิดสลิปในแอปธนาคาร/แกลเลอรี → แชร์ → เลือก "เมืองออมเงิน" (หลายรูปพร้อมกันได้)
- **สแกนแกลเลอรีเอง**: ตั้งค่า ⚙️ → เปิด "สแกนสลิปใหม่ในแกลเลอรีอัตโนมัติ" แอปจะอ่านรูปใหม่ตอนเปิดแอป
- **นำเข้าหลายรูป**: หน้าเมือง → "นำเข้าสลิปหลายรูป"
- ใส่ "ชื่อของฉัน" ในตั้งค่า เพื่อแยกเงินเข้า/เงินออกได้แม่นขึ้น · สลิปซ้ำ (เลขอ้างอิงเดียวกัน) จะไม่ถูกบันทึกซ้ำ
- อ่านในเครื่องทั้งหมด ไม่ต้องใช้เน็ต ไม่ส่งรูปออกไปไหน

## พัฒนา
```
npm ci
npm run sync            # คัดลอกไฟล์ OCR + sync เข้าโปรเจกต์ android/
cd android && ./gradlew assembleDebug
```
หน้าจอแอปอยู่ที่ `www/index.html` · โค้ดเนทีฟรับสลิปอยู่ที่ `android/app/src/main/java/th/moneygamer/citysave/`
